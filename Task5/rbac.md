### Матрица ролей и уровней доступа к данным (RBAC)


| Контур | Роль | Область видимости данных (Scope) | Разрешенные операции (Permissions) | Основные типы данных в доступе |
| :--- | :--- | :--- | :--- | :--- |
| **B2B Контур (Внутри Тенанта)** | **Tenant Owner** (Директор таксопарка) | Только своя БД (`tenant_id`) | Полный доступ (CRUD) | Финансы, тарифные сетки, отчеты, весь персонал и история поездок. |
| | **Dispatcher / Operator** (Диспетчер парка) | Только своя БД (`tenant_id`) | Чтение/Запись заказов, Чтение водителей | Активные и прошлые заказы, гео-позиции машин, карточки водителей (без фин. данных). |
| | **Driver**  | Только своя БД (`tenant_id`) + только свои строки | Чтение/Обновление своего профиля и текущего заказа | Своя телеметрия (GPS), статус смены, назначенный заказ, свой баланс. |
| | **Tenant Accountant** (Бухгалтер парка) | Только своя БД (`tenant_id`) | Чтение/Запись финансовых транзакций, Чтение профилей | Биллинг, выплаты водителям, счета, финансовая отчетность парка. |
| **Глобальный контур (Вся Платформа)** | **Platform Admin / DevOps** (Инженер платформы) | Все базы тенантов (Инфраструктурный уровень) | Управление схемами баз данных (DDL), Onboarding новых тенантов | Системные таблицы, метаданные, запуск миграций. Доступ к бизнес-данным закрыт. |
| | **ML / Data Engineer** (Разработчик моделей) | Центральное анонимизированное хранилище (Clickhouse / S3) | Чтение исторических батчей (Только чтение) | Обезличенные логи поездок за прошлые периоды, Feature Store (без имен, телефонов и полных номеров карт). |
| | **Platform Support** (Глобальная техподдержка) | Кросс-тенантный доступ по запросу (On-Demand) | Временное чтение логов конкретного `tenant_id` | Журнал ошибок (Logs), технические метаданные конкретного заказа для разбора тикетов. |
