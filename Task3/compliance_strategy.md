
## Стратегия комплаенса

### Основания идея

Основная идея в том, что используется географическое шардирование. Когда, например, житель Бразилии регистрируется в приложении, его данные записываются только внутри латиноамериканского кластера БД в Бразилии, а для роуминга используется специальный шлюз, который обезличивает пользователей при передачи вне соотв. контура. Таким образом, передается только id пользователя (guid, например) и хэш его пароля, т.е. реплицируем между континентами только необходимый минимум для авторизации.
